# Sicherheitsmeldungen für Cerberus TS

Cerberus Labs ist für die aktuelle Entwicklung und Wartung verantwortlich.
Der archivierte Altstand unter `legacy/` gehört nicht zum aktiven Build und wird nicht weiterentwickelt.

Sicherheitslücken vertraulich an die zuständigen Maintainer von Cerberus Labs melden.
Falls im verwendeten Repository private Sicherheitsmeldungen aktiviert sind, diese Funktion verwenden.
Andernfalls zunächst einen privaten Meldeweg mit den Maintainern vereinbaren.
Es ist hier noch keine öffentliche Kontaktadresse für Cerberus Labs hinterlegt.

Eine Meldung sollte Version, Transport, betroffene Funktion, Voraussetzungen, Auswirkungen und
Reproduktionsschritte enthalten. Zugangsdaten, API-Schlüssel, Tokens und personenbezogene Daten entfernen.
Aktive Exploits oder sensible Details nicht in einem öffentlichen Issue veröffentlichen.
